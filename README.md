# Название проекта
Реализованы класс продукта и класс категории. Добавлены атрибуты к классам. 
Инициализированны параметры классов через конструктор класса 

Добавлены классы продуктов Газон и Смартфон и проверка на добавление продуктов из класс Product или его субклассов.
